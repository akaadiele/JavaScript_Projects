# JavaScript Projects — Workspace Overview

A small collection of focused JavaScript projects used for learning and experimentation. Each project is self-contained with its own README and run instructions.

## Projects

- **Beast_Battle** — Browser RPG
	- What: Button-driven single-page game (Town, Store, Cave, Fight) with combat, inventory and a secret mini-game.
	- Tech: HTML, CSS, vanilla JavaScript.
	- Run: open `Beast_Battle/beast_battle.html` in a browser.
	- Docs: `Beast_Battle/readme.md`

- **Movies_Reviews** — Movie discovery + review platform (full-stack, v1)
	- What: TMDB-backed movie discovery with a review system (create/edit/delete) and a 10-star rating widget.
	- Tech: Frontend (HTML/CSS/JS, Playwright tests, ESLint) + Backend (Node.js, Express, MongoDB, Jest + Supertest).
	- Run backend:

```bash
cd Movies_Reviews/backend
npm install
npm start
```

	- Open frontend: `Movies_Reviews/frontend/index.html` in a browser.
	- Docs: `Movies_Reviews/readme.md` (detailed v1 release notes, API, tests, CI/CD, deployment)
